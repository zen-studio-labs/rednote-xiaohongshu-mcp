# Changelog

## 0.1.0

First release.

- Remote MCP server with four RedNote (Xiaohongshu, 小红书) tools: note search, note details, comments with replies, and creator profiles with their notes.
- Apify sign-in (OAuth) for Claude, ChatGPT, Cursor, VS Code, Codex and other remote MCP clients; token header as an alternative.
- Claude Code plugin with the RedNote skill: run flow for longer requests, input recipes, tool chaining and field sets.
- Client configuration examples, code examples for Python, JavaScript and HTTP, and an MCP Registry manifest.
- README in English and Simplified Chinese.
